# Frontend

Frontend website menggunakan HTML, CSS/Tailwind CSS, vanilla JavaScript, dan Supabase JavaScript SDK.

- `pages/`: halaman HTML website.
- `assets/css/`: stylesheet dan konfigurasi/style terkait Tailwind CSS.
- `assets/js/`: modul JavaScript, termasuk integrasi Supabase.
- `assets/images/`: aset gambar statis yang aman untuk disimpan di repository. Foto tugas dan galeri disimpan di Supabase Storage, bukan di hosting website.
